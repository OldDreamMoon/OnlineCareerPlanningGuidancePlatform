# Social Platform Icons

这些图标资源用于学生资料中心 `/profile` 的“外部主页账号”区域。

当前文件路径：

- `github.svg`
- `gitee.svg`
- `juejin.svg`
- `csdn.svg`
- `zhihu.svg`
- `bilibili.svg`
- `xiaohongshu.svg`
- `weibo.svg`
- `weibo.ico`
- `weibo-multicolor.svg`
- `portfolio-placeholder.svg`

来源说明：

- `github.svg`
  - 来源：GitHub 官方品牌资源包中的 `GitHub_Invertocat_Black.svg`
  - 原始地址：`https://brand.github.com/GitHub_Logos.zip`
  - 说明：当前使用黑色实心猫形态，符合资料页社交图标需求
- `gitee.svg`
  - 来源：`simple-icons` 品牌 SVG
  - 原始地址：`https://cdn.jsdelivr.net/npm/simple-icons@16.12.0/icons/gitee.svg`
- `juejin.svg`
  - 来源：`simple-icons` 品牌 SVG
  - 原始地址：`https://cdn.jsdelivr.net/npm/simple-icons@16.12.0/icons/juejin.svg`
- `csdn.svg`
  - 来源：`simple-icons` 品牌 SVG
  - 原始地址：`https://cdn.jsdelivr.net/npm/simple-icons@16.12.0/icons/csdn.svg`
- `zhihu.svg`
  - 来源：`simple-icons` 品牌 SVG
  - 原始地址：`https://cdn.jsdelivr.net/npm/simple-icons@16.12.0/icons/zhihu.svg`
- `bilibili.svg`
  - 来源：`simple-icons` 品牌 SVG
  - 原始地址：`https://cdn.jsdelivr.net/npm/simple-icons@16.12.0/icons/bilibili.svg`
- `xiaohongshu.svg`
  - 来源：`simple-icons` 品牌 SVG
  - 原始地址：`https://cdn.jsdelivr.net/npm/simple-icons@16.12.0/icons/xiaohongshu.svg`
- `weibo.svg`
  - 来源：`simple-icons` 品牌 SVG
  - 原始地址：`https://cdn.jsdelivr.net/npm/simple-icons@16.12.0/icons/sinaweibo.svg`
  - 说明：上游 slug 为 `sinaweibo`，本地统一落为 `weibo.svg`
- `weibo.ico`
  - 来源：微博官方站点 favicon
  - 原始地址：`https://weibo.com/favicon.ico`
  - 说明：当前资料页实际使用这一份 ico，兼容性更稳定
- `weibo-multicolor.svg`
  - 来源：多色版微博 SVG 资源
  - 原始地址：`https://www.logo.wine/a/logo/Sina_Weibo/Sina_Weibo-Logo.wine.svg`
  - 说明：当前仅保留为备用资源，资料页默认不使用
- `portfolio-placeholder.svg`
  - 说明：`个人网站 / 作品集` 没有统一官方品牌图标，这里先保留占位图。
  - 如需替换，请继续使用同一路径：`/social-platform-icons/portfolio-placeholder.svg`

如果后续你想手动替换某个平台图标，建议直接覆盖同名文件，这样前端代码不需要再改路径。
