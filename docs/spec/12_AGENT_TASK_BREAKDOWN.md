- 模块并行实现，但不得突破统一契约。

## 3. 关键任务 DoD
### 3.1 T-001 鉴权与 RBAC
输入：SRS `FR-001~FR-004`、API 鉴权契约。
输出：注册/登录/当前用户、角色拦截中间件。
DoD：鉴权测试通过，越权被拒。

### 3.2 T-003 AI 模块基础
输入：AI 模块规范（`06_AI_MODULE_SPEC.md`）。
输出：供应商 HTTP 适配层（WebClient）、任务路由、Prompt 模板注入、熔断回退（Resilience4j）。
DoD：调用日志可查，回退测试通过，token 与成本记录正确。

### 3.3 T-007 订单状态机
输入：订单状态机规范。
输出：状态流转服务与非法流转拦截。
DoD：状态机单元测试完整。

### 3.4 T-008 沙箱支付
输入：支付回调契约、验签规则。
输出：发起支付、回调处理、幂等实现。
DoD：重复回调无副作用。

### 3.5 T-009 模拟支付回退
输入：开关与审计要求。
输出：模拟支付接口与审计日志。
DoD：模式切换即时生效。

### 3.6 T-013 语音最小闭环
输入：P2 最小语音方案。
输出：上传->STT->LLM->TTS。
DoD：至少 1 条 E2E 成功 + 失败回退测试。

### 3.6b T-017 平台级通知系统首版
输入：`docs/spec/26_PLATFORM_NOTIFICATION_SYSTEM_SPEC.md`、`04_API_SPEC.md`、`05_DB_SCHEMA.md`。
输出：`notification_events` / `notifications` / `notification_dispatch_jobs` / `notification_dispatch_attempts` / `notification_preferences`，统一通知发布服务、WS ticket + ACK、前端通知中心与顶栏铃铛。
DoD：AI 简历异步任务、咨询/支付/售后、企业悬赏、认证审核、系统公告至少一条真实接入；`/notifications/preferences` 与 `/notifications/ws-ticket` 可用；在线实时推送与离线补偿同时成立；`COMMUNITY` 至少支持帖子回复 / 审核结果 / 举报结果中的核心事务事件，点赞等高频噪音类事件继续后置。

### 3.7 T-026 动态画像引擎
输入：SRS `FR-083~FR-089`、API 与 DB 契约。
输出：画像标签计算、证据统计、快照 upsert、事件触发刷新 + 每日兜底任务。
DoD：画像接口返回标签 + 证据 + 更新时间，规则测试通过。

### 3.8 T-F12 / T-029 / T-030 技能星图专项
输入：`docs/spec/16_SKILLS_STAR_MAP_ALIGNMENT_PLAN.md`、现有技能树 / 成长 / AI 契约。
输出：星图式 `/skills` 页面、技能概览与主攻目标能力、节点资源与定向 AI 串联。
DoD：至少完成 Phase 1 真接线；若进入 Phase 2/3，需保持技能页与 AI 主链路可回退。

## 4. 并行开发建议
可并行组：
- A 组：鉴权/社区（前后端）
- B 组：AI 模块 + AI 接口适配
- C 组：订单支付 + 后台开关
- D 组：测试与部署

同步点：
1. API 冻结后再大规模前端联调。
2. DB 冻结后再批量补测试。
3. 开关配置完成后再做最终演示彩排。

## 5. Agent 协作约束
1. 任何接口字段变更必须先更新 `04_API_SPEC.md`。
2. 枚举变更必须同步 API/DB/SRS。
3. 积分只允许账本追加。
4. 支付回调改动必须同步幂等测试。
5. `/skills` 相关新增接口、字段或配置项，优先遵循 `docs/spec/16_SKILLS_STAR_MAP_ALIGNMENT_PLAN.md` 的阶段拆分，不跨阶段混做。

## 6. Agent 协作说明

> v1 实际执行为单人 + 单 Agent 串行模式。以下角色划分为理想分工参考，实际由同一 Agent 按优先级串行/切换执行。

- 后端业务核心（鉴权、社区、成长）
- 支付订单与企业模块
- AI 模块与 AI 适配
- 前端页面与后台
- 测试与部署

## 7. Sprint 完成条件
1. 计划任务全部达到 DoD。
2. 无未处理 P0 阻塞。
3. 任何契约变更均已更新文档。

## 8. 任务拆解目标
让任意新 Agent 可以直接领取任务并执行，无需再做架构或契约决策。

## 9. 本文档范围
覆盖 v1（P0+P1+1个P2）开发、测试、部署任务。

## 10. 决策摘要
- 契约优先。
- 回退优先于冒险集成。
- 并行开发但强制同步点。

## 11. 验收标准
1. 任务拆解可直接用于看板。
2. 每个任务都有输入、输出与 DoD。
