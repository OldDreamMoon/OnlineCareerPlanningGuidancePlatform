# 管理员技能星图预览复用说明

## 页面标识
- 页面名称：管理员技能星图预览页
- 主路由：`/admin/skills/preview`
- 对应组件：`AdminSkillsPreviewPage`
- 页面定位：从技能资源治理台进入的只读结构预览工具，用于校对节点在星图画布中的位置、层级和详情表现

## 当前策略
- 当前不把该页作为独立设计稿页面推进
- 直接复用学生侧技能星图的画布、背景和详情面板骨架
- 仅在管理员模式下收起学生成长 HUD、AI 行动按钮与进度操作，保留结构验证能力

## 项目基线
- 前端技术栈：React 18 + TypeScript + Vite 5 + React Router 6
- 允许复用学生端技能星图的 Pixi 画布能力，但需要在管理员模式下隐藏学生成长 HUD 与进度动作
- 当前验收基线为宽屏桌面端，建议按 `1440px` 画板设计

## 页面目标
- 让管理员无需切换学生身份，即可直接查看节点在星图画布中的实际结构位置
- 提供“背景 + 画布 + 节点 + 详情面板”的只读预览体验
- 作为技能治理页中的结构验证工具，不承担节点 CRUD 和学习进度变更

## 信息架构
- 左上角返回条：返回技能治理页、定位当前预览节点、刷新预览
- 顶部状态卡：说明当前为管理员只读预览，展示节点总数与当前预览锚点
- 中央星图画布：背景、网格、节点、缩放、拖拽、选中态
- 底部缩放控制：缩放百分比、重置视图
- 右侧详情面板：节点路径、状态标签、节点说明、局部关系、推荐资源

## 必备模块
- 返回入口：明确回到 `/admin/skills`
- 预览模式标识：明显提示“当前不是学生正式星图，而是管理员只读预览”
- 预览锚点：显示当前 query 指定的 `nodeCode / focusNodeCode`
- 节点详情：保留路径、节点编码、更新时间、节点说明、资源列表
- 资源信息：只读展示资源标题、类型、来源、链接
- 缩放与定位：保留拖拽、缩放、重置视图、定位锚点节点

## 需要弱化或移除的学生端元素
- 不展示学生头像、昵称、成长百分比、社区贡献、近 7 日面练等 HUD
- 不展示“设为当前追踪目标”
- 不展示“发起专项 AI 面试验证”
- 不展示技能进度修改按钮

## 数据承接
- 主要接口：`GET /admin/skills/preview-tree`
- 定位参数：`nodeCode`、`focusNodeCode`
- 预览树响应沿用 `SkillTreeResponse` 结构，但管理员预览态当前允许采用简化语义：
- `summary` 可只作为节点总数统计，不要求映射真实学生成长进度
- `status` 当前可统一作为只读占位态，不要求在预览页承担学习进度解释
- `relations` 当前可为空；如为空，UI 不应强依赖连线运营信息

## 关键交互
- 打开页面时，优先按 `nodeCode` 或 `focusNodeCode` 自动居中定位
- 点击节点后，右侧详情面板切换到对应节点
- 详情面板中的路径标签可作为快速跳转入口
- 若节点存在资源，允许直接打开外部链接
- 页面刷新仅重新拉取预览树，不修改任何业务数据

## 设计方向
- 直接复用学生星图的“深色沉浸式画布”骨架，不单独要求重做视觉稿
- 顶部状态卡只需承担“结构校对 / 后台预览”提示，不需要扩展成新产品页
- 整体目标是“帮助管理员看结构”，不是“复制学生完整产品体验”

## 设计限制
- 该页为管理员工具页，不承担学生侧运营表达
- 当前第一轮只要求“节点 + 背景 + 详情”稳定可用，不要求扩成完整后台星图工作区
- 若后续需要加入局部树导航、minimap、筛选器或关系图层，可作为第二轮增强
