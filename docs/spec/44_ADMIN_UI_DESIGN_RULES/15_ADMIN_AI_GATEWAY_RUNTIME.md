# AI 网关 runtime 兼容说明

## 页面标识
- 原页面名称：AI 网关 / 运行态
- 原子路由：`/admin/ai/gateway?tab=runtime`
- 当前状态：不再作为独立工作区存在
- 当前定位：原 runtime tab 中的运行健康观察已并入服务商页与调用日志页，原配额策略治理已迁回 AI 应用运营台

## 调整原因
- 用户当前已明确要求把“每日免费额度 / 单次积分 / 服务层级权益”从 AI 网关移回 AI 应用运营台，避免技术治理与业务计费信息冗余。
- 服务商健康、成本观察、异常日志等运行视角仍有价值，但更适合拆入服务商页、调用日志页和运行配置中心的 AI 渠道快照，而不是继续保留独立 runtime tab。

## 兼容规则
- 旧入口 `/admin/ai/gateway?tab=runtime` 需要兼容跳转到 `/admin/runtime?tab=ai-channels`。
- 旧 runtime tab 中的“配额策略表格”不再出现在 AI 网关。
- 旧 runtime tab 中的“服务商成本 / 运行态摘要”分别迁到服务商页和日志页。

## 当前要求
- 若页面或文档中仍残留 “runtime tab / 配额策略” 描述，后续实现时应统一清理。
- AI 成本的技术观察仍允许在网关侧展示，但只能服务于渠道治理，不再承载积分计费配置。
