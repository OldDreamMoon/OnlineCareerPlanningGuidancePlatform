## 1. 目标
- 在“我的资料中心”之外，补一个面向他人阅读的“学生公开空间”。
- 让社区中的头像、昵称、贡献榜用户名不再只是文本展示，而是正式的人物入口。
- 先形成可审查、可答辩、可继续重构的前端一期页面，不等专门模板或完整后端契约全部就绪再开始。
- 为后续导师 / 企业查看学生公开形象、校友感展示、平台成长留痕提供统一承接页。

## 2. 页面定位
### 2.1 正确定位
`/students/:studentUserId` 的定位是：
- 学生在平台内的公开人物页
- 社区与贡献榜中的人物入口承接页
- 学生资料中心的“对外展示面”
- 成长轨迹、公开标签、社区贡献与公开身份线索的聚合页

### 2.2 错误定位
`/students/:studentUserId` 不是：
- 学生自己的资料编辑后台
- 简历页替代品
- 完整社交主页
- 关注 / 粉丝 / 私信系统
- 公开联系方式直出页

## 3. 与资料中心的边界
### 3.1 `/profile`
- 继续承担“我的资料中心 / 编辑后台”
- 负责资料维护、隐私矩阵、安全设置、头像上传
- 关注“我如何维护自己的资料”

### 3.2 `/students/:studentUserId`
- 只承担“别人如何看到我”
- 默认只展示可公开承接的信息
- 不在页内承接资料编辑
- 更强调人物感、平台成长感、公开内容聚合感

一句话区分：

`/profile` 是后台，`/students/:studentUserId` 是门面。

## 4. 一期范围
### 4.1 当前要做
- 新增正式路由 `/students/:studentUserId`
- 社区首页帖子卡中的作者头像 / 昵称可进入公开空间
- 帖子详情中的作者身份区可进入公开空间
- 评论区中的学生作者身份可进入公开空间
- 社区贡献榜中的用户名可进入公开空间
- 页面展示以下公开信息层：
  - 基础身份摘要
  - 平台成长概览
  - 公开技能与画像标签
  - 公开社交入口
  - 最近公开足迹

### 4.2 当前不做
- 关注 / 粉丝 / 访客记录
- 站内私信
- 公开留言板
- 完整作品集管理
- 社区帖子时间线分页页
- 单独的“公开空间设置页”

## 5. 一期数据策略
### 5.1 当前现实
后端目前只有学生本人资料接口 `GET /profiles/students/me`，还没有专门的“查看任意学生公开资料”接口。

### 5.2 一期前端落地原则
因此当前一期采用“前端先落页，数据分层承接”的策略：
- 若访问的是本人公开空间：
  - 直接读取 `GET /profiles/students/me`
  - 按隐私矩阵裁切出可公开展示的信息
- 若访问的是社区中的其他学生：
  - 优先使用社区帖子、评论、贡献榜中已有的公开线索
  - 通过前端快照缓存补足一期人物页展示

### 5.3 一期限制
- 当前其他学生的学校、专业、年级、目标岗位等信息，并没有稳定的公共读取接口
- 因此一期更偏“人物入口页 + 平台足迹页”，不是完整公开资料页
- 后续若效果成立，应补真正的学生公开资料接口与头像公开读取能力

## 6. 页面结构
### 6.1 顶部导航
- 学生本人查看时，沿用学生工作台统一顶栏语言
- 其他角色查看时，使用更简洁的回跳式顶栏
- 顶部必须保留：
  - 返回社区
  - 返回贡献榜

### 6.2 Hero 区
- 头像 / 昵称 / 公开身份标签
- 一句页面定位说明
- 若资料中心有可公开字段，则以轻胶囊展示：
  - 目标岗位
  - 学校
  - 专业
  - 年级
- 右侧展示平台公开维度摘要：
  - 社区贡献分
  - 贡献榜定位

### 6.3 统计区
- 近 7 天发帖
- 近 7 天评论
- 近 7 天获赞
- 最近活跃时间

### 6.4 主内容区
- 左列：
  - 公开基础信息
  - 公开标签与成长信号
  - 公开社交入口
- 右列：
  - 平台成长概览
  - 最近公开足迹
  - 返回主链路 CTA

## 7. 展示内容规则
### 7.1 基础信息
优先展示：
- 公开昵称
- 目标岗位
- 学校
- 专业 / 年级
- 平台简介
- 荣誉与成就

无值时：
- 允许展示“暂未公开 / 暂未同步”这类清晰空态
- 不用技术性字段名提示用户

### 7.2 公开标签
- 技能标签
- 平台画像标签
- 不应出现技术调试字段或后台字段名

### 7.3 平台成长信息
- 社区贡献分
- 贡献榜名次
- 近 7 天帖子 / 评论 / 获赞
- 技能掌握 / 学习中数量
- 近 7 天 AI 面试互动次数

### 7.4 社交入口
- 仅展示用户主动配置且允许公开的链接
- 平台名应使用中文业务标签，不直接暴露内部字段

### 7.5 最近公开足迹
- 优先展示最近公开帖子或讨论参与记录
- 入口应可点击回跳原社区内容
- 作用是强化“这个人真实在平台里活动过”，而不是做完整内容主页

## 8. 隐私与可见性原则
- 一期页面必须尊重现有资料中心隐私矩阵
- 不展示手机号、微信、邮箱等敏感联系方式
- 当前学生视角的一期预览允许做合并式学生公开视图，不强行做复杂同校精确判定
- 一期的目标是“不要把不该展示的信息暴露出去”，而不是一次性做完全部精细权限

## 9. 社区接入规则
### 9.1 社区首页
- 帖子卡片中的作者头像 / 昵称可进入公开空间
- 进入公开空间前应先缓存当前帖子标题、场景与时间线索，供个人空间展示“最近公开足迹”

### 9.2 帖子详情
- 主贴作者身份区可进入公开空间
- 评论区中的学生作者身份可进入公开空间
- AI 身份内容不进入人物空间

### 9.3 贡献榜
- 用户名可进入公开空间
- 排名、分数、发帖数、评论数、获赞数可以作为公开空间一期的重要外显数据来源

## 10. 视觉要求
- 整体沿用学生资料页与社区亮色桌面端语言
- 风格关键词：
  - 清晰
  - 有人物感
  - 有成长感
  - 不是简历页，也不是后台页
- 必须避免：
  - 像资料编辑页
  - 像纯空数据占位页
  - 像泛社交主页

## 11. 后续重构方向
如果一期前端落地效果成立，后续可以继续推进：
- 独立模板页重构
- 学生公开资料读取接口
- 学生头像公开读取接口
- 更精确的隐私矩阵服务端裁切
- 更多平台足迹模块，例如最近帖子列表、精选回答、成长里程碑

## 12. 验收标准
1. 社区首页、帖子详情、评论区、贡献榜都存在进入学生公开空间的自然入口。
2. `/students/:studentUserId` 页面可稳定打开并展示至少一层公开信息。
3. 本人访问时，可看到基于资料中心的公开视图预览。
4. 非本人访问时，即使没有完整公共接口，也能依靠社区公开线索形成最小可读页面。
5. 页面文案与结构更偏“公开人物页”，而不是资料编辑页或后台页。
