## 2. 周里程碑（6-10 周）
| 周次 | 目标 | 交付物 |
|---|---|---|
| 1 | 项目骨架与鉴权 | 仓库结构、容器基线、注册登录、RBAC |
| 2 | P0 数据与社区基础 | 画像、技能树数据、帖子评论 API |
| 3 | AI 文本能力 | 简历优化、文本面试、AI 调用日志 |
| 4 | P0 稳定化 | P0 全链路演示脚本、后台基础页 |
| 5 | 订单与支付初始化 | 订单状态机、支付创建接口、回调框架 |
| 6 | P1 成长与社区 AI | 打卡任务、积分账本、AI 预回答/破冰 |
| 7 | 企业简化模块 + 内容治理 + 画像筛选 | 悬赏发布、提交、审核闭环；举报与待审队列；任务内画像筛选 |
| 8 | P2 语音亮点与回归 | 语音最小闭环、回退测试、答辩包（含治理脚本） |
| 9（缓冲） | 稳定性加固 | 缺陷修复、性能优化、脚本稳定 |
| 10（缓冲） | 最终收尾 | 文档一致性、答辩彩排 |

## 3. 依赖关系（文本图）
1. 鉴权 RBAC 是所有模块前置。
2. AI 模块基础先于 AI 工具与语音。
3. 订单状态机先于支付回调。
4. 积分账本先于成长模块。
5. 功能开关先于双轨支付演示。
6. 敏感词与策略配置先于社区强审开关。
7. 学生画像快照先于企业任务内画像筛选与社区榜单展示。
8. 统一通知基座先于多业务域通知接入与浏览器实时提醒。
