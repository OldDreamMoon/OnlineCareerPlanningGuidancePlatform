# 企业资料与认证 UI 设计规则

> 文档状态：`evolving`
> 当前版本：2026-04-09
> 适用范围：企业端 `/enterprise/profile`
> 用途：以当前真实代码为准，固定企业资料页的页内路由结构、Logo 组件语义、认证状态承接方式与资料维护边界。

## 1. 文档目标

本文件不是接口文档，也不是像素级视觉稿。

它的目标是：

- 明确企业资料页已经从旧式长页收口为页内多页路由工作区
- 固定企业资料、认证状态、通知提醒三块能力的承接边界
- 避免企业资料页继续回退到“右侧堆一栏卡片”的旧结构
- 让后续文档、测试与页面微调都以当前实现为准

一句话总结：

`企业资料页是企业身份信息、Logo、认证状态与通知提醒的统一维护入口。`

## 2. 页面定位

`/enterprise/profile` 的正确定位不是：

- 企业工作台首页
- 任务发布页
- 审核工作区
- 对外品牌展示页

它的正确定位是：

- 企业资料中心
- 企业认证状态中心
- 企业通知提醒设置入口

## 3. 页面职责边界

### 3.1 本页负责什么

- 企业身份基础资料维护
- 企业 Logo 上传、裁剪与预览
- 企业简介、公开链接与招募偏好维护
- 招聘方向标签维护
- 认证状态回看与重新提交认证
- 当前认证附件查看
- 通知提醒设置
- 密码修改入口承接

### 3.2 本页不负责什么

- 任务统计与业务提醒摘要
- 多任务搜索与筛选
- 单任务学生审核
- 社区或通知收件箱主列表
- 企业公开品牌主页

## 4. 当前真实信息架构

当前页面采用“页面头部 + 页内 Tab 路由 + 分 Tab 内容区”的结构：

1. 页面头部
2. 页内 Tab 导航
3. `profile` 资料页
4. `certification` 认证状态页
5. `notifications` 通知提醒页

### 4.1 页面头部

当前页面头部固定包含：

- 页面标题：`企业资料与认证`
- 一句简洁说明
- `返回工作台`
- `去任务中心`

它不再承担旧式 Hero 大卡、状态统计卡或历史记录卡。

### 4.2 页内 Tab 路由

当前页内路由采用查询参数控制：

- `?tab=profile`
- `?tab=certification`
- `?tab=notifications`

交互规则：

- 顶部 Tab 条为 sticky 导航
- 切换 Tab 时 URL 会同步更新
- 资料处于编辑且存在未保存修改时，禁止直接切换 Tab
- 顶栏菜单的“修改密码”通过 `/enterprise/profile?action=password` 打开密码弹窗

### 4.3 `profile` 资料页

当前 `profile` Tab 由三个板块组成：

1. 企业身份主卡
2. 企业介绍与补充信息
3. 招聘方向标签

#### 企业身份主卡

当前主卡已收口为单张整宽卡片，内部采用左右布局：

- 左侧：Logo 配置区
- 右侧：6 条基础信息

Logo 配置区当前特征：

- 使用企业 Logo 语义，不再沿用“头像”表述
- 更换按钮放在 Logo 框内部
- 不再显示右上角认证角标
- 前端支持裁剪预览与背景效果调整

右侧基础信息当前包含：

- 平台账号名（只读）
- 企业名称
- 联系人真实姓名
- 职位 / 身份
- 所在行业
- 企业规模

其中行业与规模当前使用自定义下拉组件，不再使用原生 `<select>` 的默认样式。

#### 企业介绍与补充信息

当前独立承接三类文本：

- 企业简介 `bio`
- 联系方式与外部链接 `externalLinks`
- 招募偏好与学生提示 `preferences`

这些信息保持产品化表达，不扩张为组织架构、品牌官网或多联系人系统。

#### 招聘方向标签

当前标签区支持：

- 展示已添加标签
- 编辑态新增标签
- 快捷选择建议标签
- 删除已有标签

### 4.4 `certification` 认证状态页

当前认证页已收口为居中容器，不再保留右侧长侧栏或历史记录常驻区。

当前内容包括：

- 当前认证状态主视觉
- 状态说明
- `重新提交认证` 按钮
- 当前有效提交摘要
- 审核备注
- 当前可查看的认证附件

认证页当前重点是“看清状态、补充材料、打开附件”，不再镜像管理员审核后台。

### 4.5 `notifications` 通知提醒页

当前通知提醒页直接复用共享组件 `LazyProfileNotificationPreferencesPanel`，负责：

- 展示企业可配置的通知类别
- 配置站内、浏览器、邮件等渠道
- 作为资料页内的设置板块，而不是单独的企业通知中心

## 5. 数据与交互原则

### 5.1 旧数据缓存与静默刷新

当前资料页已采用“先展示旧快照，再后台静默刷新”的模式：

- 先读本地 workspace snapshot
- 若存在快照，优先渲染最近一次可用数据
- 后台静默请求资料与认证信息
- 用户可手动刷新

### 5.2 编辑态保护

当前页面已补齐编辑保护：

- 进入编辑态后，未保存内容会阻止切换 Tab
- 底部会出现固定编辑浮条
- 自动消失的 toast 会显示在编辑浮条上方，避免遮挡

### 5.3 Logo 组件语义

Logo 当前按企业品牌标识处理，而不是用户头像：

- 文案统一使用 `Logo`
- 上传入口在 Logo 框内部
- 裁剪结果直接服务于工作台、任务页和学生侧企业标识展示

## 6. 当前实现补充（2026-04-09）

- 当前企业资料页已经真实形成 `profile / certification / notifications` 三个页内板块，不再使用旧式双栏长页。
- 当前资料接口已落地字段：
  - 基础资料：`companyName`、`realName`、`jobTitle`、`industry`、`companySize`
  - 业务补充：`hiringTags`、`bio`、`externalLinks`、`preferences`
  - Logo 元数据：`logoUrl`、`logoConfigured`、`logoContentType`、`logoUpdatedAt`
- 企业 Logo 上传与读取接口已真实存在，资料页 Logo 模块已接通前后端链路。
- 顶栏菜单当前已收口为“企业资料 + 修改密码”，不再放企业工作台或通知中心的重复入口。
- 历史提交记录常驻卡、顶部状态卡与多余技术性说明文案都已从页面中移除。

## 7. 本页不纳入范围

- 企业公开品牌主页
- 复杂品牌装修
- 企业成员协作与权限系统
- 认证历史长列表工作台
- 独立企业通知收件箱

## 8. 验收标准

1. 企业能在本页稳定维护企业资料、Logo 与招聘方向标签。
2. 企业能通过页内 Tab 清晰区分资料维护、认证状态与通知提醒。
3. 认证状态与认证附件的查看路径清楚，不再依赖旧式右侧侧栏。
4. 页面文案与交互保持商务、简洁、产品化，不再出现调试感或教学式说明。
